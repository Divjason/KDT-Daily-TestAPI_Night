Q1 객관식 · 8점

SELECT / FROM의 역할

SELECT first_name, email
FROM customer;
정답 · ②

customer Table에서 first_name과 email Column을 조회한다.

핵심

SELECT = 무엇을 조회할 것인가? FROM = 어느 Table에서 가져올 것인가?

Q2 객관식 · 8점

Alias(별칭)의 의미

SELECT
    first_name AS customer_name
FROM customer;
정답 · ③

Query 결과에서 first_name을 customer_name이라는 별칭으로 표시한다.

핵심

AS를 사용해도 Database의 실제 Column 이름이 변경되는 것은 아니다. 조회 결과에서 이해하기 쉬운 이름을 사용하는 것이다.

Q3 객관식 · 8점

WHERE / ORDER BY / LIMIT

정답 · ① 
SELECT *
FROM rental
WHERE customer_id = 10
ORDER BY rental_date DESC
LIMIT 3;
WHERE → customer_id가 10인 데이터만 선택 ORDER BY rental_date DESC → 최신 Rental부터 정렬 LIMIT 3 → 최종 3건만 조회
Q4 객관식 · 8점

CASE WHEN과 Business Rule

정답 · ②

마케터가 Business Rule을 정의하고 CASE WHEN을 이용해 그 기준에 따라 데이터를 분류할 수 있다.

핵심

SQL이 Segment 기준을 스스로 결정하는 것이 아니다. 먼저 마케터가 Heavy / Medium / Light와 같은 분류 기준을 정의하고 SQL이 그 Rule을 데이터에 적용한다.

Q7 주관식 · 12점

SQL 해석 → Marketing Question

SELECT
    customer_id,
    rental_date
FROM rental
WHERE customer_id = 5
ORDER BY rental_date DESC
LIMIT 5;
모범답안

customer_id가 5인 Customer의 Rental History 중 rental_date를 최신 순서로 정렬하여 최근 5건을 조회한다. 마케터는 이를 통해 “5번 Customer가 최근에도 Sakila를 이용하고 있는가?”, “가장 최근 Rental 시점은 언제인가?”와 같은 Marketing Question을 확인할 수 있다.

WHERE → Target Customer ORDER BY DESC → 최근 행동 우선 LIMIT → 필요한 범위 → Customer Behavior Interpretation
Q8 주관식 · 12점

Customer Pain → Gain → Value Proposition

모범답안 예시

Customer Pain [H] 콘텐츠가 많아 다음에 무엇을 볼지 선택하기 어렵다. Customer Gain [H] 자신의 취향에 맞는 콘텐츠를 빠르게 발견하고 싶다. Value Proposition Sakila는 최근 이용 빈도가 낮아진 기존 Customer가 자신의 이용 History와 취향에 맞는 다음 콘텐츠를 보다 쉽게 발견할 수 있도록 돕는다.

중요

현재 Sakila Database만으로 고객이 실제로 “선택하기 어렵다”고 느낀다는 사실까지 증명할 수는 없다. 따라서 Customer Pain은 Hypothesis로 구분할 수 있다.

Q9 주관식 · 14점

Marketing Hypothesis → SQL Validation

모범답안

① Marketing Hypothesis Rental Frequency가 낮은 기존 Customer에게 Re-engagement Campaign을 진행하면 Repeat Rental을 높일 가능성이 있다. ② Required Data rental.customer_id와 Customer별 Rental 횟수 ③ SQL로 확인 Customer별 Rental Count를 집계하여 실제 저빈도 Customer와 Frequency Distribution을 확인한다. ④ Marketing Decision 실제 데이터에 근거해 저활성 고객 기준을 정의하고 Campaign Target을 선정한다. 

SELECT
    customer_id,
    COUNT(*) AS rental_count
FROM rental
GROUP BY customer_id
ORDER BY rental_count ASC;
Marketing Hypothesis ↓ Required Data ↓ SQL ↓ Evidence ↓ Marketing Decision
Q10 주관식 · 14점

Sakila Customer Communication Plan

모범답안 예시

① Target 최근 Rental Frequency가 상대적으로 낮은 기존 Customer ② Value Proposition 이전 이용 History를 활용하여 다음에 볼 콘텐츠를 쉽게 발견하도록 돕는다. ③ Core Message “최근 즐겨본 장르와 비슷한 작품을 준비했어요.” ④ CTA — Call To Action “내 추천 콘텐츠 보기” ⑤ Media / POE Email → Owned Media ⑥ SQL Validation Customer별 Rental Frequency와 Category Preference를 분석하여 실제 Target과 추천 Content를 구체화한다.

평가 포인트

정답 문구 자체보다 Target → Value → Message → CTA → Media → Data Validation이 하나의 전략으로 논리적으로 연결되는지가 중요하다.
